# SQL Server Core Concepts

Bu klasörde SQL Server temel kavramları konu konu ayrılmıştır.

## Dosyalar
- **01-ddl.sql**: CREATE / ALTER / DROP (veri tanımlama)
- **02-dml.sql**: INSERT / SELECT / UPDATE / DELETE (CRUD)
- **03-dcl.sql**: GRANT / REVOKE (yetkilendirme örnekleri)
- **04-identity.sql**: IDENTITY ve otomatik artan Id
- **05-backup-truncate-drop.sql**: BACKUP, TRUNCATE, DROP örnekleri

## Kullanım
Scriptleri SSMS üzerinden çalıştırabilirsiniz.
